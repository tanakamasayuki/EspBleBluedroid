# ConnectionInspector

> 日本語版: [README.ja.md](README.ja.md)

Lists up to ten nearby connectable BLE devices, connects to a selected list
number, and prints connection snapshots, bonds, and queue-drop counters.

Commands are `0`–`9` to connect, `s` to rescan, `d` to disconnect, `b` to list
bonds, and `q` to print counters.
